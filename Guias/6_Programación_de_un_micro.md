# Programación de un micro

# Arduino

1. Implementar un código para enciender y se apagar (parpadee) de acuerdo a un retardo
    1. El led integrado en la placa.
    2. Un led externo a la placa.
2. Implementar un código que lea el estado de un pin en particular haciendo polling y que muestre el resultado en un led. 
El estado del pin debe manejarse utilizando un cable o boton conectado a 3.3 V o a masa.
3. Utilizando el protocolo UART,  implemente un código que haga titilar un led de acuerdo a un delay variable, este va a ser enviado via UART por el usuario.
4. Implemente un menu para que el usuario pueda selecionar entre distintos patrones de titleo para el led y mediante UART leer la opcion seleccionada e implimentarla en el led del micro.
